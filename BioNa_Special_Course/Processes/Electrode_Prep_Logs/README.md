# Electrode Prep Logs

Per-batch lab-notebook logs for electrode fabrication, covering the **full chain**:
slurry preparation → doctor-blade coating → drying → calendering → thickness measurement.

For the standard recipe/procedure these logs are measured against, see
`Processes/Slurry_Preparation_Standard.md`. For calendering settings and failure history, see
`Processes/Calendering_Notes.md`.

| Log | Sample | Temp | BioNa Exp # | Status |
|---|---|---|---|---|
| `MMB1_6A_Electrode_Prep.md` | MMB1_6A | 600 °C | 41 | Coated; thickness logged |
| `MMB1_8A_Electrode_Prep.md` | MMB1_8A | 800 °C | 42 | Coated (2 sheets); thickness logged |
| `MMB1_10A_Electrode_Prep.md` | MMB1_10A | 1000 °C | 43 | Coating failed; dried; thickness logged |
| `MMB1_12A_1C_Electrode_Prep.md` | MMB1_12A_1C | 1200 °C (1 °C/min) | 46 | Coated (2 sheets, taped blade); drying/thickness pending |

**Naming:** `<SampleID>_Electrode_Prep.md` using the underscore sample convention
(`MMB1_8A`), per `Samples/Sample_Nomenclature.md`.

**BioNa Exp #:** BioNa keeps its own global experiment ledger alongside the sample-naming
convention. Numbers above are that ledger's entries. **Exp #44 and #45 exist but are not part
of this special course** (unrelated experiments) — hence the gap between 10A (#43) and 12A_1C (#46).

> All thickness readings in these logs are **total** (coating + carbon-coated foil substrate,
> ~0.016–0.017 mm). See `Biona_Academy/Open_Questions.md` for the substrate/micrometer notes.
